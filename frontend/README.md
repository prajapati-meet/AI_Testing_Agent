# AI Test Agent — Frontend Dashboard (`frontend`)

React + Vite dashboard application for **AI Test Agent: Autonomous AI-Based Web Application Testing and Intelligent Bug Reporting**.

## Configuration
- **Port**: `5173`
- **API Gateway Base URL**: `http://localhost:8080` (configured in `src/services/api.js`)

## Pages
- `/` & `/dashboard`: Dashboard displaying project title and microservice status cards
- `/login`: Placeholder Login form
- `/register`: Placeholder Registration form

## Build & Run
```bash
# Install dependencies
npm install

# Start development server on http://localhost:5173
npm run dev

# Create production build
npm run build
```
